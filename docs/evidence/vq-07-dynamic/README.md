## Two evidence groups

### A. Real end-to-end integration (19–21) — genuine HTTP

The page ran with **no fixture parameter**: every machine movement came from
real `POST /api/demo/simulation` calls to Agent A's merged transport (#35).
Playwright logged 14 HTTP requests, all HTTP 200 with
`vorqyn.demo-sim/request/1` envelopes and cumulative trace replay. Observed:

- sim clock advanced to **9000 ms**, 18 kernel steps, sequence 18/18;
- fault injected through the real endpoint — ROV measured optical quality
  dropped to **0.086** (factor 0.12 applied) while sonar stayed independent
  (**0.612**); inspector showed the kernel's active fault record;
- `Replay history` re-executed the trace through the stateless API →
  **"Replay identical ✓ deterministic"**.

## Known issues / honest limitations

1. **Shared-shell 200% overflow (P2, pre-existing, forbidden path):** at 200%
   zoom, `.header-actions` in the merged site header overflows by 89px
   (documentElement scrollWidth 1529 vs 1440). Verified that with only the
   shell contained, the mission page content itself has NO overflow — the
   defect is entirely in the shared shell, which this workstream may not
   edit. Coordinated fix needed from the shell owner (e.g. `flex-wrap` /
   `overflow: hidden` on `.header-actions` at large zoom).
2. **Fixture plateau:** recorded responses end at 6500 ms; further advances
   keep returning the recording. Real-API captures (19–21) demonstrate open-
   ended stepping.
3. **IAB screenshot note:** the in-app browser compositor produced torn
   captures of this WebGL page; the evidence set was captured with a real
   Playwright Chromium instead (same URLs, same build). Not a product defect.
4. **FOLLOW** tracks the selected machine by translating camera + orbit
   target by observed pose deltas — it does not interpolate or predict.
