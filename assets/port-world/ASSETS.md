# PORT-001 asset provenance & licensing

Requirement: Issue #19 — record external asset/texture licenses; prefer
original geometry. This pack prefers original geometry exclusively.

## Geometry — 100% original, generated in-repo

- All five `.glb` files are produced procedurally by
  `tools/generate.js` (committed in this repository) from hand-authored
  constants in that file. No downloaded models, no scanned data, no
  third-party geometry of any kind.
- `world.json`, `previews/plan-view.svg`, `manifest.json` are generated by the
  same tool from the same constants.
- The fictional world ("PORT-001 / Kerameion Basin") is an invented composite.
  No map tiles, GIS data, bathymetry or real-port survey data were used; no
  geographic parity is claimed.

## Textures, materials, fonts

- **None.** All materials are glTF PBR base-color factors plus normalized
  ubyte vertex colors (`COLOR_0`). There are no image textures to license.

## Preview tooling (runtime-only, not distributed in assets)

- `tools/preview.html` loads **three.js r180** (MIT License, Copyright © 2010-2026
  three.js authors) from a pinned URL
  `https://cdn.jsdelivr.net/npm/three@0.180.0/` at **runtime, in the browser,
  for preview convenience only**. three.js is not bundled into, required by, or
  distributed with the asset pack or the repository build; the committed GLBs
  contain no three.js code. MIT full text: https://github.com/mrdoob/three.js/blob/dev/LICENSE
- If offline, point the importmap at any local three r180 install; the GLBs
  are standard glTF 2.0 and load with any conformant loader.

## Screenshots

- `previews/render-*.png` are unmodified captures of the real render described
  in `previews/RENDER_LOG.md` (three r180 + the committed GLBs, in-browser).
- `previews/plan-view.svg` is generated (same generator); it embeds no fonts
  (generic `monospace` family reference only).
